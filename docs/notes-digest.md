- **claude-31**: gcc2.7.2 loop hoisting of `extern const` float/double loads (claude-31, func_80112F80): every load of an `extern const f32/f64 D_8010xxxx` inside a loop is loop-invariant and loop.c hoists it to the preheader when threshold*lifetime >= insn_count; the original (li.s/li.d constants) often does NOT hoist a constant that is used only in one straight-line block (e.g. 4 uses between calls).
